## "el jakeo"
como sabrán, render se "duerme" a los 5 minutos despues de no tener uso, por lo mismmo hice un "jakeo"
el sitio uptimerobot permite hacer consultas cada 5 minutos a un sitio, por lo que en el backend, 
en este caso lo puse en naves, pero ustedes deberán hacer un controller justamente para estando, con el siguiente código

@GetMapping("/health")
public ResponseEntity<String> health() {
    return ResponseEntity.ok("OK");
}

este justamente retorna un ok cada 5 minutos, usando el uptimerobot, lo que si deben agregar esta dependencia al pom
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-actuator</artifactId>
</dependency>

y en el application.properties
management.endpoints.web.exposure.include=health,info
management.endpoint.health.show-details=always
este de abajo, justamente ya está, pero se tiene que editar con lo que está ahora
spring.autoconfigure.exclude=org.springframework.boot.autoconfigure.security.servlet.SecurityAutoConfiguration,org.springframework.boot.actuate.autoconfigure.security.servlet.ManagementWebSecurityAutoConfiguration

con este pequeño cambio, se puede tener el backend andando siempre sin necesidad de pagar los 7 dólares

##cambios en el App.jsx

algo que se nota al seguir agregando páginas es que justamente se va haciendo muy grande ese código, por lo mismo, una manera de liberarlo y dejarlo más dinámico
se hico la carpeta routes dentro del src, esta contiene el config.jsx dentro de ese archivo está todo explicado para que sea más simple el hacer el cambio,
además de que el mismo archivo App.jsx está ya listo para este dinamismo, si no se sienten cómodos haciendo eso, está bien, no tienen que hacer ese cambio, pero
en caso de estresarse viendo tanto código, pueden hacerlo, este es un cambio opcional la verdad

##tablas dinámicas
se agregaron tablas dinámicas, estas permiten llegar y llenarse, así solo ponen los datos, la manera de hacerlo es así

{
  type: "table",
  title: "Usuarios",
  columns: ["ID", "Nombre", "Edad"],
  data: [[1, "Juan", 28], [2, "Ana", 34]]
}

esto tomando en cuenta el template "Section.jsx" una manera rápida y simple de hacer tablas
